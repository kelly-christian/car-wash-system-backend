## Project Name

Car Wash System Backend

## Project Description

A REST API built with Spring Boot for managing car wash operations.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Postman

## Steps to Run the API

1. Install Java and PostgreSQL.
2. Create the project database in PostgreSQL.
3. Configure the database connection in `src/main/resources/application.properties`.
4. Open a terminal in the project root folder.
5. Run the application:

   ```bash
   mvn spring-boot:run
   ```

6. Wait for Spring Boot to start.
7. Open Postman and test the API endpoints.

## Postman Collection

Import `car-wash-system-midterm.postman_collection.json` into Postman to test the API requirements.
